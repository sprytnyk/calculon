A notepad that calculates as you type

Calculon is a natural-language notepad calculator. Write lines with money, units and dates, and see the answers beside each line. It runs on Linux, Windows and macOS, in English and Ukrainian.

Features

Two themes

Glacier is the default and uses slate blue, as on this page. Ember uses warm greys and orange. Both have dark and light modes and can follow your system setting.

Sheets are plain files

Each sheet is a .txt file in a folder you choose. Sync, search and back up your sheets with the tools you already use.

Folders, pins and trash

Group sheets in folders, pin favourites and find them with search. Deleted sheets stay in the trash until you empty it.

Rates that work offline

Calculon downloads exchange rates once a day and saves them for offline use.

English and Ukrainian

Write in English or Ukrainian, or mix them in one sheet. Numbers follow the interface language, with 1,234.56 or 1 234,56.

Spell check

Check English and Ukrainian spelling with your system's dictionaries. Calculon skips numbers, units and variable names.

Help and shortcuts

The Help sheet explains the calculation syntax with examples. Open it with Cmd+Shift+H on macOS or F1 on Windows and Linux. Keyboard Shortcuts in the Help menu lists the keys.

Vim mode

Move and edit with Vim keys in Normal, Insert and Visual modes. To turn it on, open the Vim page in Settings. It comes from side-vim.

Focus mode and always on top

Press Ctrl+Shift+F for Focus Mode. It hides the menu bar, the sidebar and the date of the last rates update, so only your sheet is left. On macOS the menu bar stays at the top of the screen. Always on Top keeps Calculon above other apps. Both are in the View menu.

Questions

Is it free?

Yes. Calculon is open source under the MIT licence, and the code is on GitHub.

Does it work with Soulver sheets?

Mostly. Calculon follows Soulver's calculation syntax, so most sheets work in both apps. Trip timelines differ. Soulver sets their start and end in its interface. Calculon uses @from and @to lines, which Soulver doesn't read. Calculon isn't made by Soulver's authors.

Does it work offline? What does it send?

Calculon runs on your computer and uses the network only for exchange rates and, when you open About, to ask GitHub whether a newer version is out. It downloads rates once a day from open.er-api.com or Frankfurter. Offline, it uses the last saved rates. You don't need an account, and Calculon doesn't track you.

Where are my sheets?

On first start, Calculon asks where to keep them and suggests ~/Documents/Calculon. Each sheet is a .txt file there. Folders in the app are folders on disk. You can choose another folder in Settings and sync it with your usual tools.

How do I turn on spell check?

Calculon uses the spell checker on your system. On Linux that's Hunspell. To install it with English and Ukrainian dictionaries on Debian or Ubuntu, run: 

sudo apt install libhunspell-1.7-0 hunspell-en-us hunspell-uk

On macOS, install Hunspell with Homebrew and put the en_US and uk_UA dictionaries in ~/Library/Spelling. The README has the steps. On Windows, Calculon uses Windows' own spell checker. For Ukrainian, add the language in Settings > Time & language > Language & region.

Turn on Check Spelling in the View menu. The shortcut is Cmd+Option+S on macOS or F7 on Windows and Linux.
