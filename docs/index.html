A notepad that calculates as you type

Write lines with money, units and dates, and see the answers beside each line. Try 20% off $80 or 10 km in miles. Calculon runs on Linux, Windows and macOS. Write in English or Ukrainian.

Features

Two themes

Choose the slate blue Glacier theme or the orange Ember theme. Both have light and dark modes and can follow your system setting. Glacier is the default.

Sheets are plain files

Calculon saves each sheet as a .txt file in a directory you choose. Sync, search and back up your sheets with the tools you already use.

Directories, pins and trash

Group sheets in directories and pin the ones you use often. Search by name or sheet text. Restore deleted sheets from Trash.

Exchange rates offline

Calculon downloads exchange rates once a day and saves them for offline use.

English and Ukrainian

Use either language for the menus and write in both on the same sheet. Choose a number format in Settings. The default is 1,234.56.

Spell check

Check English and Ukrainian spelling with your system's dictionaries. Calculon skips numbers, units and variable names.

Help and hints

The Help sheet has examples you can try in your own sheet. Open it with Cmd+Shift+H on macOS or F1 on Windows and Linux. Hover over a red ! next to a line to see why it has no answer.

Vim mode

Turn on Vim mode in Settings to use Normal, Insert and Visual modes. Press K in Normal mode to show or hide a hint. See Keyboard Shortcuts in the Help menu. Calculon uses side-vim.

Focus mode and always on top

Focus Mode hides the sidebar and the rates date. It also hides the menu bar on Linux and Windows. Use Ctrl+Shift+F, or Cmd+Shift+F on macOS. The View menu also has Always on Top.

Questions

Is it free?

Calculon is free. The MIT-licensed code is on GitHub.

How do I install it?

Download the archive for your system from Releases and unpack it. On Linux, run ./calculon. On Windows, run calculon.exe.

The Windows build isn't code-signed, so SmartScreen may ask you to confirm the first start. Click More info, then Run anyway. On macOS, drag Calculon.app into Applications. The app isn't notarized, so macOS blocks it the first time. Try to open it, then go to System Settings > Privacy & Security and click Open Anyway.

How do I update it?

Open About Calculon in the Help menu, or in the Calculon menu on macOS. It checks GitHub and shows a link when a new version is out. Download it and replace the old copy. Your sheets and settings stay where they are.

Does it work with Soulver sheets?

Most sheets that use Soulver's syntax work in Calculon, including line references from Soulver exports. Calculon uses its own @from and @to lines for trip timelines. In Soulver, set the trip's start and end in the app's interface. Calculon is an independent project.

What does the total on the bottom bar add up?

It adds the results of the whole sheet, subtotals included. If the sheet has money, it adds the money. Otherwise, it adds the results with the most common kind of unit, or plain numbers if there are no units. If Calculon has no exchange rate for a currency in the sheet, the bar shows which currency it is instead of a total.

Can I write numbers as 1 234,56?

Yes. Choose 1,234.56, 1.234,56, 1 234,56 or 1 234.56 on the Numbers page in Settings. The format is used for what you type and for the answers, whatever the menu language. The default is 1,234.56, so 1,250 is one thousand two hundred and fifty.

Put semicolons between list items and function arguments, as in round(1234; 2). The same page sets which currency a bare $ stands for. The default is US dollars.

Does it work offline? What does it send?

Calculon calculates on your computer. It gets rates from open.er-api.com or Frankfurter and uses the last saved rates when you're offline. When you open About, it checks GitHub for a new version. Calculon works without an account or tracking.

Can I use my own exchange rates?

Yes. Enter the URL of your source on the Exchange Rates page in Settings, for example your own Frankfurter server. It should return JSON like this. 

{"base": "USD", "rates": {"EUR": 0.92, "UAH": 41.3}}

The README lists what the reply needs.

Where are my sheets?

Calculon suggests ~/Documents/Calculon on first launch. You can choose another directory in Settings. Each sheet is a plain .txt file, and directories in the sidebar are directories on disk. Deleted sheets go to .trash in the same place until you empty Trash.

If a file changes on disk while you edit it, choose Save a copy to save your edits in a new sheet in the same directory.

How do I turn on spell check?

Calculon uses the spell checker on your system. On Linux that's Hunspell. To install it with English and Ukrainian dictionaries on Debian or Ubuntu, use this command. 

sudo apt install libhunspell-1.7-0 hunspell-en-us hunspell-uk

On macOS, install Hunspell with Homebrew and put the en_US and uk_UA dictionaries in ~/Library/Spelling. The README has the steps. On Windows, Calculon uses Windows' own spell checker. For Ukrainian, add the language in Settings > Time & language > Language & region.

Turn on Check Spelling in the View menu. The shortcut is Cmd+Option+S on macOS or F7 on Windows and Linux. The Spell Check page in Settings shows which dictionaries Calculon found.
